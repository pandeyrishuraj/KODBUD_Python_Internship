# File Renaming Automation

A simple Python script that automatically renames files in a folder using a sequential naming pattern.

## Features

- Reads files from a selected folder
- Renames files automatically
- Uses sequential names like `file_1.txt`, `file_2.txt`
- Uses Python's `os` module
- Helps automate file management

## Concepts Used

- Python `os` module
- File and folder handling
- `os.listdir()`
- `os.rename()`
- `os.path.join()`
- For loop
- `enumerate()`
- String formatting

## How It Works

The program reads the files from the specified folder and renames them sequentially.

Example:

`abc.txt` → `file_1.txt`

`hello.txt` → `file_2.txt`

`notes.txt` → `file_3.txt`

`python.txt` → `file_4.txt`
